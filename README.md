# SkillBridge – Learn Together. Grow Together. 

**SkillBridge** is a Student Peer Learning Platform designed to help students learn new skills, share their knowledge, and connect with fellow students.

The platform encourages collaborative learning by allowing students to teach and learn from each other through peer-to-peer sessions and a credit-based learning system.

 **Live Demo:** https://skill-brigde-seven.vercel.app/

##  Features

- **User Registration & Login:** Secure student authentication.
- **Student Dashboard:** Manage learning activities and track progress.
- **Student Profiles:** Create profiles and showcase skills.
- **Find Learning Partners:** Connect with students who can teach or learn specific skills.
- **Skill Exchange:** Share knowledge and learn from peers.
- **Study Sessions:** Schedule and manage peer-learning sessions.
- **Learning Resources:** Access useful educational materials.
- **Feedback System:** Share feedback and improve the learning experience.
- **Credit System:** Encourage students to contribute by teaching others.
- **Admin Dashboard:** Manage users and platform activities.

##  Getting Started

Follow these steps to run the project locally.

### Prerequisites

- XAMPP
- Visual Studio Code
- Web browser
- MySQL

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/your-username/SkillBridge.git
```

**2. Move the project**

Copy the project folder into:

```text
C:\xampp\htdocs\
```

**3. Start XAMPP**

- Start Apache.
- Start MySQL.

**4. Import the database**

- Open `http://localhost/phpmyadmin`
- Create or select the database.
- Import `database/skillbridge.sql`.

**5. Configure database connection**

Update your database credentials in:

```text
config/database.php
```

**6. Run the project**

Open your browser and visit:

```text
http://localhost/SkillBridge/
```

##  Project Objective

The main objective of SkillBridge is to create an interactive learning environment where students can exchange knowledge, develop new skills, and support one another academically.

Instead of depending entirely on traditional teaching methods, SkillBridge promotes collaborative and student-driven learning.
